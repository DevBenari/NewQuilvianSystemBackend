## 1. Masalah yang diperbaiki

Penanda "pernah diralat" dokumen Optik hanya melihat nomor versi. Addendum koreksi yang sempat
tersimpan pada dokumen Optik — sebelum `BE-43` menutup jalur itu — tidak membuat dokumen bertanda
"pernah diralat". Dokter yang membaca berkas tidak tahu bahwa isi dokumen pernah dikoreksi
(`RM-CF-R4-01`).

## 2. Proses bisnis

| Keadaan dokumen Optik | "Pernah diralat" |
| --- | --- |
| Versi 1, tanpa addendum | Tidak |
| Versi 1, ada addendum **koreksi** yang terlanjur tersimpan | **Ya** (baru) |
| Versi 1, hanya addendum **pengesahan** | Tidak — pengesahan bukan ralat (`RM-DEC-049`) |
| Versi 2 atau lebih | Ya (perilaku lama) |
| Addendum koreksi pada versi lama, dokumen sudah direvisi | Ya pada baris daftar (versi terakhir); rincian versi lama juga bertanda |

**Contoh.** Sebelum 10 November, petugas menambahkan addendum koreksi pada refraksi Ibu Sari
versi 1 ("visus OS 6/12, bukan 6/15"). Sebelumnya berkas menampilkan refraksi itu tanpa penanda;
sekarang tampil "Pernah diralat", dan pembaca tahu harus membuka riwayat addendumnya.

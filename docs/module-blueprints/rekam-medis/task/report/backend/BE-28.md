## 1. Masalah yang diperbaiki

Sejak `BE-25`, setiap penutupan klinis kunjungan tercatat satu kali beserta jalurnya. Namun
seluruh pemanggil belum menyebut jalurnya, sehingga semua baris tercatat `EncounterStatusPatch` —
seolah setiap kunjungan ditutup lewat PATCH status Registrasi. Laporan mutu tidak dapat membedakan
kunjungan yang ditutup dokter, perawat, IGD, pemulangan rawat inap, atau tagihan.

**Contoh:** pasien rawat inap dipulangkan Senin, tagihannya lunas Kamis. Sebelum task ini baris
tutup klinisnya bersumber `EncounterStatusPatch`. Sekarang bersumber `InpatientDischarge`, waktunya
Senin, dan finalisasi tagihan Kamis tidak mengubah apa pun.

## 2. Proses bisnis

**Tujuan:** sumber penutupan klinis mencerminkan jalur yang sebenarnya menutup kunjungan.

**Pelaku:** tidak ada tindakan baru. Setiap jalur penutupan yang sudah ada kini menyebut dirinya.

| Jalur | Sumber yang dicatat | Persetujuan |
| --- | --- | --- |
| PATCH status kunjungan ke `Completed` (`PatientEncounterController`) | `EncounterStatusPatch` | `RM-DEC-068` |
| Penyelesaian antrean dokter (`DoctorQueueController`) | `DoctorQueue` | `RM-DEC-068` |
| Penyelesaian screening perawat (`NurseStationQueueController`) | `NurseStation` | `RM-DEC-068` |
| Kunjungan IGD selesai, termasuk disposisi pulang/rujuk (`EmergencyVisitService`) | `EmergencyVisit` | `RM-DEC-067` |
| Disposisi IGD ke rawat inap — langsung maupun sesudah penahan tuntas | `EmergencyAdmissionDisposition` | `RM-DEC-067` |
| Pemulangan rawat inap (`InpDischargeService.Closure`) | `InpatientDischarge` | `RM-DEC-069` |
| Finalisasi tagihan (`BillingFinalizationService`) | `BillingFinalization` | `RM-DEC-070` |

**Aturan yang berlaku:**

| Keadaan | Hasil |
| --- | --- |
| Penutupan pertama | Sumber jalur itu tercatat |
| Penutupan berikutnya lewat jalur lain, mis. tagihan sesudah pemulangan | Baris pertama dipertahankan; sumber dan waktu tidak berubah |
| Disposisi IGD yang tipenya menuntut permintaan rawat inap, ditutup tanpa sumber eksplisit | Diturunkan menjadi `EmergencyAdmissionDisposition` |

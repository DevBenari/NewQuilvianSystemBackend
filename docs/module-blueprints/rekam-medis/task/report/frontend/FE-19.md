## 1. Keadaan yang ditemukan di awal

`BE-47` menambah bagian "Rencana kontrol" pada rincian ringkasan pulang di backend. Panel detail
dokumen (`medical-record-document-panel.jsx`) menggambar seluruh `sections` dari server dengan
`sections.map(...)` tanpa daftar label tetap, sehingga bagian baru itu **sudah** tampil tanpa
perubahan layar. Yang belum ada: penjaga agar sifat itu tidak hilang kelak, dan bukti layar.

---

## 2. Proses bisnis dari sisi pengguna

1. Petugas membuka berkas pasien → linimasa → baris "Ringkasan Pulang".
2. Panel detail menampilkan bagian dokumen sesuai urutan server: … "Instruksi tindak lanjut" →
   **"Rencana kontrol"** (misalnya `10-10-2026 — Poli Penyakit Dalam — dr. Maya`) → "Ditandatangani".
3. Ringkasan lama tanpa tanggal kontrol tidak menampilkan bagian kosong.

## 1. Keadaan yang ditemukan di awal

Layar berkas rekam medis menggambar tombol "Tambah addendum" setiap kali `/authority` menjawab
`isAllowed = true`. Sejak `BE-43`, addendum koreksi pada Pemeriksaan Refraksi dan Resep Optik ditolak
`400`, dan `/authority` mengirim `isCorrectionAllowed = false` untuk kedua jenis itu. Tanpa task ini,
pengguna tetap ditawari tombol yang pasti ditolak.

## 2. Proses bisnis dari sisi pengguna

| Keadaan dokumen | Yang tampil |
| --- | --- |
| Dokumen Optik ditandatangani | **Tanpa tombol.** Keterangan: "Koreksi dokumen Optik dibuat sebagai revisi di layar Optik. …" |
| Dokumen Optik terkunci tanpa tanda tangan | Hanya tombol **"Sahkan isi catatan"**, ditambah keterangan arahan yang sama |
| Dokumen lain (CPPT, asesmen, Rehab) | Tidak berubah: tombol koreksi, dan tombol pengesahan bila berlaku |
| Server lama tanpa `isCorrectionAllowed` | Dianggap koreksi diizinkan — perilaku sama dengan sebelumnya |

Bila server tetap menolak (`400` `VAL-RM-B01`), pesan server tampil apa adanya dan isian form tidak
hilang (`RM-FE-031`). Perilaku ini sudah ada sejak `FE-08`/`FE-12` dan kini dibuktikan uji.
